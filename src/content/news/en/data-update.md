### Does all data need to be updated in real time?
Depending on the functional needs of the solution, **real-time data is not always necessary**. That is why some of the features that optimize mobile app performance rely on **dynamic caches**, which reduce recurring calls to the server by temporarily storing this data in a small database on the device.
The main advantage of this feature is that, **by generating less server traffic with a smaller infrastructure, we can serve more users consuming the same service and save costs**.
Within this type of feature, it is also worth building transfer protocols that incrementally update the data stored in the mobile device's internal database which, combined with data synchronization, can save more than 75% in mobile data consumption.
